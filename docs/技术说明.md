# 技术说明

## 视频动作的导入（`tools/import_videos.py`）

素材是用 `video_prompts/claude_idle_greenscreen.png` 当**首帧和尾帧**做的 10 秒图生视频：每段都从标准站姿开始、回到标准站姿结束，
所以动作之间直接切换也没有接缝。导入时：

1. **绿幕抠像**：按「绿色程度」g − max(r, b) 做软 alpha，再向内收缩一点，去掉半透明的绿边；
2. **去光晕**：按 g − r 压低残留的绿光，且半透明像素只允许出现在实体像素 3 像素以内，飘在外面的光晕整块去掉；
3. **去溢色**：g ≤ (r + b) / 2 + 6，边缘带再限制 g ≤ 0.8 r；
4. **固定裁切**：每段取全片的包围盒，所有帧同一裁切，画面不跳；
5. **配准**：先导入待机视频，用它第一帧对 idle 立绘求一次缩放与位移，所有视频共用这个映射；分辨率不同的视频先缩放到待机视频的尺寸；
6. 输出 `aoi_pet/assets/claude/video/<动作>/NNN.webp` 和 `manifest.json`（帧率、帧数、裁切框、映射）。

文件名和用途的对照见 `video_prompts/提示词.md` 第五节（如 `stand by.mp4` → 待机，`search.mp4` → 拿放大镜）。

## 播放（`aoi_pet/claude_painter.py`）

- 按原帧率（24fps）直接播，不做帧间混合；播视频时窗口按 48Hz 刷新，每帧正好停两拍，节奏均匀。
- 帧按需加载，后台线程预先解码接下来几帧，只缓存最近用过的 96 帧。
- 程序化的呼吸、歪头、轻摆在视频上全部关闭（视频里本来就有）；只有拖拽、下落、落地挤压这类物理反应保留。
- 有视频时不再出现静态立绘：没有对应视频的场景继续播待机视频，只出气泡和特效；补上视频重新导入即可。

### 切换为什么不会闪

- **交叉淡化**：每个画面先画进各自的离屏图层，把整层乘上权重（DestinationIn），再用不透明的 Plus 相加。
  直接 `setOpacity` 叠画的话，两张图中途都只有一半不透明，合起来约 75%，人物会整个变淡一下。
- **往左走**：走路视频镜像播放。镜像前后的两张图交叉淡化会让发饰一边淡出一边淡入，看起来就是闪；
  所以改成「转身」：横向收窄到约 35%，在最窄处换朝向再展开。有 `walk_left.mp4` 时直接用它，不镜像。

## 走路（`aoi_pet/window.py`）

视频里是原地迈步，窗口只在迈步段（0.8–8.0 秒）移动，速度 52 px/s，对应视频里的步幅，脚不打滑。
开着重力时站在任务栏上只左右走；关掉重力后会斜着走，有 `walk_down` / `walk_up` 视频时还会直接上下走。

## 行为状态机（`aoi_pet/brain.py`）

状态：待机、散步、拖拽、下落、睡觉，外加一次性动作。动作时长取自视频长度；随机动作池和点击反应池只包含已有视频的动作。

跟着 Claude 干活时，工作姿势至少保持 4 秒；思考只有持续 3 秒以上才会接管画面。这样 Claude 在读文件 / 思考之间快速切换时，
她不会每秒换一个动作。

## Claude 联动的数据流

```text
Claude 桌面版 Code 标签页 ──mod──┐
终端 claude ──────────钩子──────┼─→ %LOCALAPPDATA%\CrossPet\state\claude-state.json ─→ sources/activity.py
                                │
              mod / 状态栏脚本 ─┴─→ claude-quota.json（官方 5 小时 / 每周百分比）  ─→ sources/quota.py
~/.claude/projects/**/*.jsonl ─────────────────────────────────────────────────→ claude_usage.py
Claude 桌面版进程 / 前台窗口 ──────────────────────────────────────────────────→ sources/desktop_app.py
                                                        └─ 全部汇总到 claude_link.py ─→ 窗口和行为状态机
```

- **mod**（`integrations/claude_mod`）：Claude Code 2.1.287 起的 mod 引擎。接入时复制到 `~/.claude/mods/claude-pet`，
  并登记在 `settings.json` 的 `env.CLAUDE_CODE_PLUGIN_DIRS`（Windows 上用 `;` 分隔，只增删自己那一项）。
- **钩子**（`integrations/claude_hook.py`）：永远 exit 0、不往 stdout 写东西，出错也不影响 Claude。
  同一个会话里 mod 已经在写状态（记在 `mod-sessions.json`）时，钩子自动让位。
- **自动出现**：会话开始或你发消息时，如果桌宠没开着就把它叫出来；从菜单「退出」过的话不会自动出现，直到你自己再打开一次。
- 所有通道只记录事件名、工具名、时间和额度百分比，不含对话内容；桌宠不发任何网络请求。
