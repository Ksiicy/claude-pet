# Claude 桌宠 · 10 秒动作视频提示词

参照 [dsh-pet-indesktop](https://github.com/MerZlin/dsh-pet-indesktop) 的素材规范，用 AI 视频工具「图生视频」生成。

## 一、准备

参考图：同目录的 `claude_idle_greenscreen.png`（1920×1080，纯绿 #00FF00，人物头顶约 20%、脚底约 85%、水平居中）。

## 二、生成设置（以可灵 / 即梦为例）

| 项 | 设置 |
|---|---|
| 模式 | 图生视频 → **首尾帧**（可灵叫「首尾帧」，即梦叫「首尾帧 / 智能多帧」） |
| 首帧 | `claude_idle_greenscreen.png` |
| 尾帧 | **同一张** `claude_idle_greenscreen.png` ← 最关键：保证动作结束时回到标准站姿，动作之间才能无缝衔接 |
| 时长 | 10 秒（工具只有 5 秒就选 5 秒，节奏表按比例压缩） |
| 比例 / 清晰度 | 16:9，1080p，能选「高品质 / 专业模式」就选 |
| 镜头 | 固定镜头 / 关闭运镜 |

每段生成 2～4 次，挑**人物没变形、衣服没变、首尾和参考图最像**的那一条。
免费版带水印的话也没关系，只要水印别压在人物身上（后面流水线会补成绿色）。

## 三、通用提示词（每段都放在最前面）

```text
Q版动漫少女，橙色长卷发，头戴橙色花朵和黑白缎带发饰，白橙黑配色洛丽塔连衣裙，双手捧着一本深棕色的书。
纯绿色背景 #00FF00，背景全程不变，没有阴影、地面、杂物、渐变和边框。
固定机位，镜头不推不拉不摇，画面只有人物在动。
人物始终在画面正中原地动作，双脚落点不离开画面中心，不向任何方向平移；
人物大小、位置、比例全程与第一帧一致，头顶、脚底和两侧都不出画、不贴边。
角色外观（发型、发饰、衣服、书）全程保持完全一致，不换装、不变形。
动作柔和自然、有节奏，头发和裙摆随动作轻轻摆动。
第一帧和最后一帧是同一个标准正面站姿（与参考图完全一致），动作结束时自然回到这个站姿并静止。
```

**负面提示词**（工具支持就填）：

```text
镜头移动, 推拉摇移, 背景变化, 阴影, 地面, 人物平移, 出画, 人物变形, 多余的手指, 换装, 发型改变, 文字, 字幕, 水印, 闪烁
```

## 四、各个动作（接在通用提示词后面）

**第一批先做这 6 段就够用**：待机、走路、挥手、看书、被摸头、被戳。其余的可以以后再补。

### 1. 待机呼吸 `idle`（循环）
```text
0–3 秒：安静站立，轻轻呼吸，肩膀微微起伏，眨一次眼。
3–7 秒：头轻轻向一侧歪一下又回正，头发随之轻摆，再眨一次眼。
7–10 秒：恢复正面站姿，轻轻呼吸，最后静止在标准站姿。
动作幅度很小，像在发呆。
```

### 2. 走路 `walk`（程序负责移动窗口，视频里原地走）
```text
0–1.5 秒：身体转向画面右侧，呈四分之三侧身。
1.5–8.5 秒：保持侧身，原地小碎步踏步走，左右脚交替抬起落下，共约 8 步，节奏均匀；身体随步伐轻微上下起伏，头发和裙摆随步伐摆动；双脚始终踩在原地不前进。
8.5–10 秒：转回正面，停在标准站姿。
```
（往左走时程序会把画面镜像，所以只需要这一段。）

### 3. 挥手 `wave`
```text
0–2 秒：抬头看向前方，露出微笑，右手放开书举到脸旁。
2–7 秒：右手左右挥动三次打招呼，身体随挥手轻轻摇摆，表情开心。
7–10 秒：右手放下重新捧好书，回到标准站姿。
```

### 4. 看书翻页 `read`
```text
0–2 秒：低头，双手把书打开。
2–8 秒：专注阅读，眼睛随文字移动，中间用一只手翻一页，翻页后继续读。
8–10 秒：合上书，抬头，回到标准站姿。
```

### 5. 被摸头 `pat`
```text
0–1.5 秒：微微一愣，抬眼向上看。
1.5–8 秒：闭上眼睛，脸颊泛红，头像被抚摸一样左右轻轻蹭动，露出幸福的笑容，身体轻轻摇晃。
8–10 秒：睁开眼，害羞地笑一下，回到标准站姿。
```

### 6. 被戳 `click`
```text
0–1 秒：身体轻轻一颤，惊讶地睁大眼睛，嘴巴张成小圆形。
1–6 秒：鼓起脸颊假装生气，抱紧书转头看向一边，然后忍不住偷偷看回来。
6–10 秒：噗嗤笑出来，恢复平静，回到标准站姿。
```

### 7. 伸懒腰 `stretch`
```text
0–2 秒：双手把书举起。
2–6 秒：举着书向上伸展身体，踮一下脚，闭眼打一个小哈欠。
6–10 秒：放下手臂，揉揉眼睛，重新捧好书，回到标准站姿。
```

### 8. 被拎起来 `drag`
```text
0–2 秒：身体像被从头顶轻轻提起，双脚离开原位一点点，惊讶地睁大眼睛。
2–8 秒：悬空状态，双脚轻轻晃动，紧紧抱住书，表情慌张又有点好笑，头发和裙摆向下垂并随晃动摆动。
8–10 秒：慢慢落回原位站稳，松一口气，回到标准站姿。
```

### 9. 打瞌睡 `sleep`
```text
0–3 秒：眼皮慢慢变沉，打一个小哈欠。
3–8 秒：抱着书闭眼打瞌睡，头一点一点地往下垂，身体轻轻摇晃。
8–10 秒：猛地惊醒，揉揉眼睛，回到标准站姿。
```

### 10. 思考 `thinking`（跟着 Claude 干活时用）
```text
0–2 秒：一只手松开书，食指抵住下巴。
2–8 秒：歪头思考，眼睛向上看，偶尔轻轻点头，像想到了什么。
8–10 秒：手放回书上，回到标准站姿。
```

### 11. 完成啦 `happy`（Claude 完成任务时用）
```text
0–2 秒：眼睛一亮，露出灿烂的笑容。
2–7 秒：抱着书原地开心地小跳两下，落回原位，眯眼笑。
7–10 秒：平静下来，回到标准站姿。
```

## 五、更多动作（文件名 = 用在哪里）

桌宠已经认识下面这些文件名。做好任意一段，放进 `video_prompts/videos/`，然后运行 `python tools/import_videos.py`，对应的场景就会自动换成视频。还没做的场景会先用待机视频顶着。

**有分辨率可选时选 1080p**：现在 480p 的素材放到 100% 以上会有点软。

### 走路的不同方向（解决镜像、上下移动）

| 文件名 | 用在哪里 | 动作要点 |
|---|---|---|
| `walk_left.mp4` | 往左走（就不用再左右镜像，发饰不会换边） | 和 walk 相同，只是转向画面**左侧**，四分之三侧身原地小碎步 |
| `walk_down.mp4` | 关掉重力后往屏幕**下方**走 | 正面朝镜头，原地踏步，像朝观众走来 |
| `walk_up.mp4` | 关掉重力后往屏幕**上方**走 | 转身背对镜头，原地踏步，像往远处走，看得到后脑勺和长发 |

`walk_down` 示例：

```text
0–1 秒：保持正面站姿，准备迈步。
1–8.5 秒：正面朝镜头原地小碎步踏步，左右脚交替抬起落下，共约 20 步，身体随步伐轻微上下起伏，书抱在胸前，头发和裙摆随步伐摆动；双脚始终在原地，不前进不后退。
8.5–10 秒：停下，回到标准站姿。
```

`walk_up` 示例：

```text
0–1.5 秒：慢慢转身背对镜头。
1.5–8.5 秒：背对镜头原地小碎步踏步，左右脚交替抬起落下，长发和发饰缎带随步伐摆动；双脚始终在原地。
8.5–10 秒：转回正面，回到标准站姿。
```

### 跟着 Claude 干活

| 文件名 | 用在哪里 | 动作要点 |
|---|---|---|
| `writing.mp4` | Claude 在写代码 / 改文件 | 拿出一支羽毛笔，在书上认真写字，偶尔停下想一想 |
| `typing.mp4` | Claude 在跑命令 | 面前浮现一个小小的半透明键盘，手指快速敲击，结束时键盘消散 |
| `searching.mp4` | Claude 在上网查资料 | 拿出放大镜到处看，若有所思，结束时放大镜消散 |
| `listening.mp4` | 你刚发出消息 | 侧耳倾听、点头，表情专注 |
| `asking.mp4` | Claude 在等你回答 / 授权 | 抬头看着镜头，歪头，手比一个「请」的手势，期待地等待 |
| `oops.mp4` | 出错了 | 吓一跳，慌张地翻书，挠挠头，不好意思地笑 |

道具（笔、键盘、放大镜）记得写上**渐渐出现、结束前渐渐消失**，这样首尾才能回到只拿着书的标准站姿。

### 持续状态：拖拽、下落、睡觉（循环播放，做法不一样）

| 文件名 | 用在哪里 |
|---|---|
| `drag.mp4` | 被鼠标拎起来的时候（循环） |
| `fall.mp4` | 被甩出去、在空中的时候（循环；没有的话用 drag） |
| `sleep.mp4` | 鼠标 5 分钟不动、睡着的时候（循环） |

这三段会**一直循环播放**，所以首尾帧应该是「那个状态本身」，而不是标准站姿，否则每 10 秒就会站起来一次。做法分两步：

1. 先用标准站姿当首帧，生成一段「进入这个状态」的视频。比如睡觉："慢慢闭上眼，抱着书低下头睡着"。
2. 从这段视频里**截最后一帧**（睡着的样子）当新的参考图，**首帧、尾帧都用它**，再生成一段 10 秒的循环。比如："保持睡着，抱着书，呼吸起伏，头偶尔轻轻一点"。

第 2 段命名为 `sleep.mp4` 放进来就行。拖拽也一样："双脚离地悬空、轻轻晃腿、抱紧书、有点慌张"。

### 唱歌 `sing.mp4`（右键「动作 → 唱歌」，闲着时也会随机出现）

首帧、尾帧都用 `claude_idle_greenscreen.png`。通用提示词 +

```text
0–1.5 秒：轻轻吸一口气，抬起头，露出微笑，一只手松开书放在胸前。
1.5–8 秒：闭上眼睛开心地唱歌，嘴巴随旋律一张一合，身体随节奏左右轻轻摇摆，头也跟着轻轻点；
身边飘出几个小小的橙色音符，慢慢上升并淡出；头发和裙摆随摇摆轻轻摆动。
8–10 秒：唱完最后一句，睁开眼睛害羞地笑一下，音符全部消散，手放回书上，回到标准站姿。
```

### 拿放大镜查资料 `searching.mp4`（右键「动作 → 拿放大镜查资料」；Claude 上网查资料时也用它）

首帧、尾帧都用 `claude_idle_greenscreen.png`。通用提示词 +

```text
0–2 秒：一只手松开书，手中由虚到实地渐渐出现一个金色边框的小放大镜。
2–8 秒：举着放大镜认真地左看看、右看看，再凑近书本仔细看，眼睛在镜片后面显得大大的；
看到有趣的地方时眼睛一亮，轻轻点头，像是找到了答案。
8–10 秒：放大镜由实到虚渐渐消散，手放回书上，回到标准站姿。
```

放大镜一定要写「渐渐出现 / 渐渐消散」，首尾才能回到只拿着书的标准站姿。

## 六、做好之后

把每段 mp4 按上面的文件名命名，放进 `video_prompts/videos/`，然后运行：

```bash
python tools/import_videos.py
```

导入会抠绿幕、按脚底对齐、转成透明帧序列，桌宠重启后就按 24fps 原速播放。
